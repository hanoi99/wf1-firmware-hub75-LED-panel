WF1 Firmware – Vendoring preparation 0.1.3-dev

- Removed remote Arduino library dependencies from platformio.ini.
- Added scripts/vendor-dependencies.sh to copy exact resolved packages from
  the existing .pio/libdeps/huidu_hd_wf1 cache into local lib/ folders.
- Added third-party attribution/license inventory.
- Kept the ESP32 PlatformIO platform pinned to the previously tested commit;
  the platform/toolchain is handled separately from Arduino libraries.
- Updated firmware version string and README.

IMPORTANT:
Run `bash scripts/vendor-dependencies.sh` before the next build. The script
requires the existing .pio/libdeps cache populated by the previous successful
build. It copies complete library folders, including their upstream metadata
and license files. It does not flash the WF1.
